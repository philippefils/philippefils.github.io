EMBEDDED SYSTEMS & BLUETOOTH

Bluetooth RC Car

Upgrade of an obstacle avoidance robot with Bluetooth control and a custom handheld controller.

Bluetooth Arduino Embedded Systems C++ Serial Communication

OVERVIEW

From autonomous robot to Bluetooth-controlled vehicle.

This project upgraded an existing obstacle avoidance robot into a remotely controlled vehicle using Bluetooth communication.

A new operating mode was added to the robot, allowing the user to control its movement remotely while retaining the existing robot functionality.

The project included both the modification of the robot itself and the development of a custom handheld controller with a joystick and pushbuttons for movement and mode selection.

SYSTEM ARCHITECTURE

Two embedded systems connected wirelessly.

The system consists of a Bluetooth-enabled robot and a dedicated handheld controller. The controller sends commands wirelessly to the robot, which interprets the received serial data and controls the vehicle accordingly.

Robot

An HC-05 Bluetooth module configured as the master was integrated into the robot to provide wireless serial communication with the controller.

Controller

An Arduino Nano-based controller uses a joystick and pushbuttons to generate movement and operating-mode commands.

BLUETOOTH COMMUNICATION

Wireless serial communication.

Bluetooth communication was implemented using HC-05 modules. The Bluetooth interface provided a serial communication link between the handheld controller and the robot.

Controller inputs were translated into commands and transmitted to the robot. The robot then processed the received information to determine the requested movement or operating mode.

CUSTOM CONTROLLER

Joystick and pushbutton interface.

A custom remote controller was developed around an Arduino Nano. A joystick provides directional control while pushbuttons are used for additional commands and operating-mode selection.

The controller firmware was written in C++ and was responsible for reading the user inputs, interpreting the requested action, and transmitting the corresponding commands over the Bluetooth link.

ROBOT MODIFICATION

Adding a new operating mode.

The existing obstacle avoidance robot was modified to support Bluetooth-controlled operation. The new mode allows commands received from the remote controller to control the robot's movement.

This required integrating the Bluetooth communication layer with the existing embedded control software and adapting the robot's operating logic to respond to remote commands.

EMBEDDED SOFTWARE

Firmware for the controller and robot.

The project involved embedded C++ development for both the controller and Bluetooth communication system.

Development was performed using the Arduino IDE and PlatformIO within Visual Studio Code. The firmware handled input acquisition, Bluetooth serial communication, command processing, and robot control.

PROTOTYPING

Rapid embedded hardware development.

The controller was developed through breadboard prototyping and hand soldering. This allowed the input hardware, Arduino Nano, and Bluetooth communication interface to be integrated and tested before being used as a complete remote-control system.

FUTURE IMPROVEMENTS

Potential extensions.

  • Design a dedicated PCB for the handheld controller.
  • Improve the mechanical enclosure and ergonomics of the controller.
  • Add additional control modes and user inputs.
  • Improve command handling and communication feedback.
  • Expand the robot with additional sensors and autonomous behaviours.
