ROBOTICS & CONTROL

Dynamic Controller for a Robotic Manipulator Arm

Dynamically controlled inverse-dynamic system developed in ROS and Gazebo with joint-space, task-space, stiffness, and damping control.

ROS Gazebo Control Systems Robotics

PROJECT OVERVIEW

Dynamic control of a robotic manipulator

The objective of this project was to implement and test a dynamically controlled inverse-dynamic system for a robotic manipulator. The controller was developed to operate in both joint-space and task-space while allowing the dynamic behavior of the robot to be adjusted through stiffness and damping parameters.

The system was developed using ROS and Gazebo, allowing the controller to interact with a simulated robotic manipulator while providing a framework for testing different control configurations and operating conditions.

The controller was evaluated by commanding the manipulator to reach defined positions, applying external perturbations, and adjusting control parameters to observe the resulting behavior.

CONTROL ARCHITECTURE

Inverse-dynamic control system

The controller uses an inverse-dynamic approach to calculate the torque commands required to produce the desired manipulator behavior. Joint-state information is used as feedback while velocity references and desired positions define the commanded motion.

The system was designed to support both joint-space and task-space control. This allowed the manipulator to be controlled either through individual joint behavior or through higher-level end-effector objectives.

JOINT-SPACE CONTROL

Joint-level dynamic control

Joint-space control operates directly on the individual joints of the robotic manipulator. Desired joint positions and velocity references are compared with the measured joint state to determine the required control response.

The dynamic controller uses this feedback to generate torque commands while accounting for the desired stiffness and damping behavior of the system.

TASK-SPACE CONTROL

End-effector control

Task-space control provides a higher-level method of controlling the manipulator by defining the desired behavior of the robot's end effector rather than specifying every joint independently.

This approach allows the controller to translate task-level objectives into the corresponding joint behavior required to move the manipulator toward the desired configuration.

DYNAMIC BEHAVIOR

Adjustable stiffness and damping

A key feature of the controller is the ability to adjust stiffness and damping parameters during operation. These parameters influence how the manipulator responds to position errors and external disturbances.

The parameters can be modified through ROS services, allowing different dynamic behaviors to be evaluated without modifying the underlying controller implementation.

ROS INTEGRATION

Distributed control through ROS

The control system was implemented as multiple ROS nodes that communicate through the ROS framework. This modular architecture separates the controller functions and allows individual parts of the system to be developed and tested independently.

Custom ROS services were developed to provide runtime adjustment of control parameters. ROS parameters were also used to configure the controller and simulation environment.

SIMULATION & TESTING

Controller testing in Gazebo

Gazebo was used to simulate the robotic manipulator and evaluate the controller before deployment to physical hardware. Simulation scenarios were used to test position tracking, dynamic response, and stability under external disturbances.

The manipulator was commanded to reach defined positions while the controller response was observed. External forces and perturbations were also introduced to evaluate how the system responded and returned toward its desired state.

FUTURE IMPROVEMENTS

Future improvements

Future development could extend the controller with additional control strategies and more extensive testing across different trajectories, loads, and disturbance conditions.

Additional validation on physical robotic hardware would also provide an opportunity to evaluate the controller's performance under real-world mechanical effects and sensor feedback.
